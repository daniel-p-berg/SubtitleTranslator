# SubtitleTranslator

## اس میک پر نجی سیٹ اپ

اپنی API کی اسناد macOS Keychain میں شامل کریں اور کسی بھی میڈیا فولڈر کا انتخاب کریں۔ پھر میڈیا ٹولز کی تصدیق کریں. ایپ میں کوئی اکاؤنٹ، ٹیلی میٹری یا ڈویلپر کے زیر انتظام سرور نہیں ہے.

1. سیٹ اپ شروع کریں
2. Homebrew انسٹال کریں
3. لاپتہ ٹولز انسٹال کریں
4. Keychain میں API چابیاں محفوظ کریں
5. میڈیا فائل منتخب کریں
6. مضامین تیار کریں
7. mpv میں کھلا

```bash
brew install ffmpeg mkvtoolnix mpv
```

ایپ کو دوبارہ شروع کرنے کے بعد زبان کی تبدیلیاں لاگو ہوتی ہیں۔

API اسناد macOS Keychain میں رہیں . ذیلی عنوان کی پروسیسنگ اور میڈیا فائلیں اس میک پر رہیں. OpenAI کو صرف ترجمہ کرتے وقت ذیلی عنوان متن موصول ہوتا ہے۔ OpenSubtitles صرف تلاش کے میٹا ڈیٹا وصول کرتا ہے جب آپ تلاش کرتے ہیں. درخواستیں براہ راست ان فراہم کنندگان کو جاتی ہیں۔

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
