
# SubtitleTranslator

## Pengaturan peribadi pada Mac ini

Tambah credential API anda ke macOS Keychain dan pilih folder media mana sahaja. Kemudian mengesahkan alat media. Aplikasi ini tidak mempunyai akaun, telemetri, atau pelayan yang dikendalikan oleh pemaju.

1. Memulakan Setup
2. Pasang Homebrew
3. Pasang alat yang hilang
4. Simpan Kunci API ke Keychain
5. Pilih fail media
6. Persiapkan Subtitles
7. Terbuka di mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Perubahan bahasa berlaku selepas memulakan semula aplikasi.

Kenali API tinggal di macOS Keychain . Pemprosesan subtitle dan fail media kekal di Mac ini. OpenAI menerima teks subtitle hanya apabila anda menerjemahkan. OpenSubtitles menerima metadata carian hanya apabila anda mencari. Permintaan pergi terus ke pembekal itu.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
