
# SubtitleTranslator

## Soukromé nastavení na tomto Mac

Přidejte své údaje API do macOS Keychain a vyberte si jakýkoli mediální složku. Pak potvrďte mediální nástroje. Aplikace nemá účet, telemetrii ani server provozovaný vývojářem.

1. Začněte nastavení
2. Nainstalovat Homebrew
3. Nainstalovat chybějící nástroje
4. Uložte klíče API do Keychain
5. Vyberte soubor médií
6. Připravte titulky
7. Otevřeno v mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Změny jazyka se použijí po restartování aplikace.

Závěry API zůstávají v macOS Keychain . Zpracování titulků a mediální soubory zůstávají na tomto Macu. OpenAI přijímá text s titulky pouze při překladu. OpenSubtitles přijímá metadata vyhledávání pouze při vyhledávání. Žádosti jdou přímo k těmto poskytovatelům.
