
# SubtitleTranslator

## इस मैक पर निजी सेटअप

macOS Keychain में अपनी एपीआई क्रेडेंशियल जोड़ें और किसी भी मीडिया फ़ोल्डर का चयन करें। तो मीडिया टूल की पुष्टि करें। ऐप में कोई खाता, टेलीमेट्री या डेवलपर द्वारा संचालित सर्वर नहीं है।

1. सेटअप प्रारंभ करें
2. Homebrew स्थापित करें
3. अनुपलब्ध उपकरण स्थापित करें
4. Keychain में एपीआई कुंजी सहेजें
5. एक मीडिया फ़ाइल चुनें
6. उपशीर्षक तैयार करें
7. mpv में खुला

```bash
brew install ffmpeg mkvtoolnix mpv
```

ऐप को पुनरारंभ करने के बाद भाषा परिवर्तन लागू होते हैं।

एपीआई क्रेडेंशियल macOS Keychain में रहते हैं . उपशीर्षक प्रसंस्करण और मीडिया फ़ाइलें इस मैक पर रहते हैं। OpenAI को केवल जब आप अनुवाद करते हैं तो उपशीर्षक पाठ प्राप्त होता है। OpenSubtitles केवल जब आप खोज करते हैं तो खोज मेटाडेटा प्राप्त करता है। अनुरोध सीधे उन प्रदाताओं को जाता है।
