
# SubtitleTranslator

## এই ম্যাকের ব্যক্তিগত সেটআপ

macOS Keychain এ আপনার এপিআই শংসাপত্র যোগ করুন এবং যেকোনো মিডিয়া ফোল্ডার নির্বাচন করুন। তাহলে মিডিয়া সরঞ্জামগুলো নিশ্চিত করুন। অ্যাপটিতে কোনো অ্যাকাউন্ট, টেলিমেট্রি বা ডেভেলপার পরিচালিত সার্ভার নেই।

1. সেটআপ শুরু করুন
2. Homebrew ইনস্টল করুন
3. অনুপস্থিত সরঞ্জামগুলি ইনস্টল করুন
4. Keychain এ এপিআই কী সংরক্ষণ করুন
5. একটি মিডিয়া ফাইল নির্বাচন করুন
6. সাবটাইটেল প্রস্তুত করুন
7. mpv এ খোলা

```bash
brew install ffmpeg mkvtoolnix mpv
```

অ্যাপ্লিকেশনটি পুনরায় চালু করার পরে ভাষা পরিবর্তনগুলি প্রযোজ্য।

এপিআইয়ের শংসাপত্রগুলো macOS Keychain-এ থাকবে । সাবটাইটেল প্রসেসিং এবং মিডিয়া ফাইল এই ম্যাকের উপর থাকবে। OpenAI শুধুমাত্র আপনার অনুবাদ করার সময় সাবটাইটেল পাঠ্য গ্রহণ করে। OpenSubtitles শুধুমাত্র যখন আপনি অনুসন্ধান করেন তখনই অনুসন্ধান মেটাডেটা গ্রহণ করে। অনুরোধগুলি সরাসরি সেই প্রোভাইডারদের কাছে যায়।
