
# SubtitleTranslator

## Προσωπική εγκατάσταση σε αυτό το Mac

Προσθέστε τα πιστοποιητικά API σας στο macOS Keychain και επιλέξτε οποιοδήποτε φάκελο μέσων ενημέρωσης. Τότε επιβεβαιώστε τα μέσα ενημέρωσης. Η εφαρμογή δεν έχει λογαριασμό, τηλεμετρία ή διακομιστή που λειτουργεί από τον προγραμματιστή.

1. Ξεκινήστε την εγκατάσταση
2. Εγκατάσταση Homebrew
3. Εγκατάσταση Λείπτων εργαλείων
4. Κράτα τα κλειδιά API στο Keychain
5. Επιλέξτε ένα αρχείο μέσων ενημέρωσης
6. Προετοιμάστε υποτιτλήσεις
7. Ανοιχτό στο mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Οι αλλαγές γλώσσας ισχύουν μετά την επανεκκίνηση της εφαρμογής.

Τα πιστοποιητικά API παραμένουν στο macOS Keychain . Η επεξεργασία υπότιτλων και τα αρχεία μέσων ενημέρωσης παραμένουν στο Mac. Η OpenAI λαμβάνει το υπότιτλο μόνο όταν μεταφράζετε. Η OpenSubtitles λαμβάνει μεταδεδομένα αναζήτησης μόνο όταν κάνετε αναζήτηση. Οι αιτήσεις πηγαίνουν απευθείας σε αυτούς τους παρόχους.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
