
# SubtitleTranslator

## Configuration privée sur ce Mac

Ajoutez vos identifiants API à macOS Keychain et choisissez n'importe quel dossier multimédia. Alors confirmez les outils des médias. L'application n'a pas de compte, de télémétrie ou de serveur exploité par le développeur.

1. Début de la configuration
2. Installez le Homebrew
3. Installez les outils manquants
4. Enregistrez les clés API à Keychain
5. Choisissez un fichier multimédia
6. Préparez les sous-titres
7. Ouvert à mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Les changements de langue s'appliquent après le redémarrage de l'application.

Les accréditations de l' API restent à macOS Keychain . Le traitement des sous-titres et les fichiers multimédias restent sur ce Mac. OpenAI ne reçoit le texte sous-titré que lorsque vous traduisez. OpenSubtitles ne reçoit les métadonnées de recherche que lorsque vous effectuez une recherche. Les demandes vont directement à ces fournisseurs.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
