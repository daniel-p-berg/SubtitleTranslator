
# SubtitleTranslator

## 在这个Mac上设置私人

添加您的API凭证到macOS Keychain,并选择任何媒体文件<unk>. 然后确认媒体工具. 应用程序没有帐户,远程测量或开发者操作的服务器.

1. 启动设置
2. 安装Homebrew
3. 安装缺失的工具
4. 保存API密钥到Keychain
5. 选择一个媒体文件
6. 准备字幕
7. 在mpv开放

```bash
brew install ffmpeg mkvtoolnix mpv
```

在重新启动应用程序后使用语言变化.

API 凭证留在macOSKeychain . 字幕处理和媒体文件留在这个Mac上. 当您翻译时,OpenAI只收到字幕文本. 当您搜索时,OpenSubtitles只会收到搜索元数据. 要求直接向这些供应商进行.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
