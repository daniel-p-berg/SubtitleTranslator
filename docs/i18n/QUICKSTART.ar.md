# SubtitleTranslator

## الإعداد الخاص على هذا ماك

إضافة إثباتات API الخاصة بك إلى macOS Keychain واختيار أي مجلد إعلامي. ثم تأكد من أدوات الإعلام. لا يوجد في التطبيق حساب أو جهاز قياس عن بعد أو خادم يديره المطور.

1. البدء في الإعداد
2. قم بتثبيت Homebrew
3. قم بتثبيت الأدوات المفقودة
4. حفظ مفاتيح API إلى Keychain
5. اختر ملف الوسائط
6. إعداد الترجمة
7. مفتوحة في mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

تطبق تغييرات اللغة بعد إعادة تشغيل التطبيق.

تفويضات الـ API تبقى في macOS Keychain . معالجة الترجمة وملفات الوسائط تبقى على هذا ماك تتلقى OpenAI نصًا تحت الترجمة فقط عند الترجمة. تتلقى OpenSubtitles بيانات البحث فقط عند البحث. الطلبات تذهب مباشرة إلى هؤلاء المقدمين.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
