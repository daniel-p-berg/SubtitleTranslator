
# SubtitleTranslator

## 這個 Mac 上的私人設定

在 macOS Keychain 中添加您的API認證, 然後確認媒體工具. 該應用程式沒有帳戶,遠程測量或開發者操作的伺服器.

1. 啟動設定
2. 設置Homebrew
3. 設置缺失的工具
4. 在 Keychain 保存API鍵
5. 選擇媒體檔案
6. 準備字幕
7. 在 mpv 打開

```bash
brew install ffmpeg mkvtoolnix mpv
```

在重新啟動應用程式後,會發生語言變更.

您的資料將留在 macOS Keychain. 這部電腦將處理字幕和媒體檔案留在這台Mac上. OpenAI只有當您翻譯時才會收到字幕文字. OpenSubtitles只有在您搜索時才會接收搜尋元數據. 要求直接向這些供應商進行.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
