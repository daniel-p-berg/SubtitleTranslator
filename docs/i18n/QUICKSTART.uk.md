
# SubtitleTranslator

## Приватне налаштування на цьому Mac

Додайте свої ознаки API в macOS Keychain і виберіть будь-яку медіа-политку. Тоді підтвердіть медіа-інструменти. У додатку немає рахунку, телеметрії або сервера, який управляє розробник.

1. Почати налаштування
2. Установка Homebrew
3. Установка відсутніх інструментів
4. Зберігайте ключі API в Keychain
5. Виберіть медіафайл
6. Підготуйте субтитри
7. Відкрито в mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Зміни мови застосовуються після перезавантаження додатку.

Документи API залишаються в macOS Keychain . Переробка субтитров і медіафайли залишаються на цьому Mac. OpenAI отримує текст підзаголовків тільки при перекладі. OpenSubtitles отримує метаданні пошуку тільки при пошуку. Запроси йдуть безпосередньо до тих постачальників.
