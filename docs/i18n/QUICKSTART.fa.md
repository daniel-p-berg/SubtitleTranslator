# SubtitleTranslator

## تنظیم خصوصی روی این مک

اسناد API خود را به macOS Keychain اضافه کنید و هر پوشه رسانه ای را انتخاب کنید. پس ابزار رسانه ها رو تایید کن این اپلیکیشن هیچ حساب، telemetry و یا سرور توسعه دهنده ای ندارد.

1. راه اندازی شروع
2. نصب Homebrew
3. نصب ابزار گمشده
4. کلید های API را به Keychain ذخیره کنید
5. یک فایل رسانه ای را انتخاب کنید
6. زیرنویس آماده کن
7. باز در mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

تغییرات زبان پس از راه اندازی مجدد اپلیکیشن اعمال می شود.

اسناد API در macOS Keychain باقی مانده پردازش زیرنویس و فایل های رسانه ای روی این مک باقی می مانند. OpenAI متن زیرنویس را تنها زمانی دریافت می کند که شما ترجمه کنید. OpenSubtitles فقط وقتی شما جستجو می کنید متادتا دریافت می کند. درخواست ها به طور مستقیم به این ارائه دهندگان میرسند.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
