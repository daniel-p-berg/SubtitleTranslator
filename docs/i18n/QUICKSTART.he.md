# SubtitleTranslator

## הגדרות פרטיות במק הזה

הוסף את אישור האפפי שלך ל- macOS Keychain ולבחר כל תיק מדיה. אז אישר את כלי התקשורת. האפליקציה אין חשבון, טלמטריה, או שרת מנוהל על ידי המפתחים.

1. התחל להגדיר
2. תקין Homebrew
3. תקין כלים חסרים
4. שמור מפתחות API ל Keychain
5. בחר קובץ מדיה
6. להכין כותרות
7. פותח ב mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

שינויים בשפה יחולו לאחר התחלה מחדש של האפליקציה.

רשימות ה-API נשארות ב-macOS Keychain . עיבוד הכותרות וקבצים מדיה נשארים במק הזה. OpenAI מקבלת טקסט תחתונים רק כאשר אתה מתרגם. OpenSubtitles מקבלת מטא נתונים חיפוש רק כאשר אתה חיפש. בקשות הולכים ישירות למספקים האלה.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
