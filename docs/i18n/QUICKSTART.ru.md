
# SubtitleTranslator

## Частная настройка на Mac

Добавьте свои аккредитации API к macOS Keychain и выберите любую папку медиа. Тогда подтвердите средства массовой информации. У приложения нет аккаунта, телеметрии или сервера, управляемого разработчиком.

1. Начало настройки
2. Установка Homebrew
3. Установка отсутствующих инструментов
4. Сохранить ключи API в Keychain
5. Выберите медиафайл
6. Подготовить субтитры
7. Открыто в mpv

```bash
brew install ffmpeg mkvtoolnix mpv
```

Изменения языка применяются после перезагрузки приложения.

Удостоверения API остаются в macOS Keychain . Обработка субтитров и медиафайлы остаются на Mac. OpenAI получает текст с субтитрами только при переводе. OpenSubtitles получает метаданные поиска только при поиске. Запросы направляются непосредственно к этим поставщикам.

[OpenAI](https://platform.openai.com/api-keys) | [OpenSubtitles](https://www.opensubtitles.com/en/consumers) | [mpv](https://mpv.io/installation/)
